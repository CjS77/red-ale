Scriptable GnuCash. Made for agents.

red-ale reads and edits GnuCash books without the GnuCash program. Drive it from the command line, from your own programs over JSON-RPC, or hand the ledger to AI agents over MCP. Anything it saves, GnuCash 5.17 opens with no warnings and no lost data.

01 — What it does

GnuCash, without the windows.

Script your bookkeeping, build tools on top of your GnuCash books, or let AI agents do it for you. Talk to red-ale like you talk to your accountant.

AI READY
No. Entry Covers Status
101 Accounts & transactions Accounts, transactions, voids, reversals, transfers and reconciling POSTED
102 Investments Commodities, currencies, prices, lots, capital gains and stock splits POSTED
103 Business Customers, vendors, employees, jobs, invoices, bills, expense vouchers, orders, tax tables, billing terms and payments POSTED
104 Check & Repair The same checks and repairs as GnuCash's Check & Repair POSTED
105 Safekeeping GnuCash's backups, its .log journal and its lock, so two programs never write the same book POSTED

GnuCash?

  • Double-entry accounting
  • Battle-tested since 1998
  • Multi-currency
  • For individuals to SMEs

Red-ale runs on your existing GnuCash DBs

Staffing the back office

Three clerks. One ledger. Zero windows.

The Clerk

red-ale exec

Runs one method or a whole script from the command line.

The Teller

red-ale serve

Open a book and handle JSON-RPC from curl, any program you write.

The Agent

red-ale mcp

Run the MCP Server in your favorite harness, whether it's Claude Code, Codex, or 7 others.

02 — Install

Installed with one line.

Linux or macOS

Option A — Installer script

RECOMMENDED 
$ curl -fsSL https://github.com/CjS77/red-ale/releases/latest/download/install.sh | sh

Option B — From source

Needs Rust (rustup picks the toolchain), git and a C compiler such as gcc or clang. Installs to ~/.cargo/bin.

git clone https://github.com/CjS77/red-ale.git
cd red-ale
cargo install --path crates/red-ale

03 — Command-line Demo

A household book, from blank page to balanced.

Five steps from the walkthrough. Output is piped through jq to keep it short; jq is optional.

~/red-ale-demo — step 01 
$ mkdir red-ale-demo && cd red-ale-demo
$ red-ale exec --create --book home.gnucash book.info


                    

                


                

                    
Clerk's note · step 01

                    
Open a new book

                    
exec opens a book, runs one method on it, saves if anything changed, and
                        closes it.

                        Here it creates home.gnucash and describes it: an empty book with only a root account.

Takeaways

            

                

                    §1
                    
Say what you want

                    
Use the MCP Server and talk to your agent like you talk to your accountant.

                

                

                    §2
                    
Detailed help

                    
Not sure how to do something? Just ask. The full guide is embedded into the MCP server.

                

                

                    §3
                    
Need a report?

                    
Most of the GnuCash reports have been ported. But if you need something specific ask your agent to
                        write it for you! And save it for next time.

                

                

                    §4
                    
Open it in GnuCash

                    
If you still want old-school control, just open the book in GnuCash. All your changes will be saved as usual..
